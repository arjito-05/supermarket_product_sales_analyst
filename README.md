# supermarket_product_sales_analyst
## project overview
Superstore Sales Analysis is a data analytics project that explores sales transaction data to identify sales trends, product performance, customer segments, and regional performance.

The project demonstrates an end-to-end data analysis workflow, starting from data cleaning and exploratory data analysis to data visualization and dashboard development.

## objectives
This project aims to answer several business questions:
1. How does sales performance change over time?
2. Which sub-category performs best?
3. Which region contributes the most sales?
4. Which customer segment generates the highest sales?
5. Which shipping mode is most frequently used?
6. Which products generate the highest sales?

## analysis
### Sales Trend
Sales were analyzed over time to identify changes in sales performance and determine periods with higher or lower sales.
### Product Category
Sales were grouped by product category to identify which category contributes the most to overall sales.
### Regional Performance
Sales were analyzed by region to compare regional performance.
### Customer Segment
Customer segments were analyzed to determine which segment contributes the most to sales.
### Top Products
Products were ranked based on total sales to identify the highest-performing products.

## key insight
The analysis provides insight into :
1. Sales trends over time
2. Product category performance
3. Regional sales performance
4. Customer segment contribution
5. Top-performing products
6. Shipping mode usage
